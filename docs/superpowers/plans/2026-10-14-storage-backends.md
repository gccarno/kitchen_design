# Storage Backends (Phase 1 of Mobile + Cloud) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Put project and photo storage behind async interfaces with two backends each:
- **Local disk** (today's behaviour) for dev and tests.
- **Postgres + Google Cloud Storage** for the hosted app.

Plus a one-off import of `./data` into the cloud backends.

**Architecture:**
- **Interfaces:** `ProjectStore` (project records) and `BlobStore` (photo bytes and later exports), defined in `src/lib/storage/store.ts`.
- **Implementations:**
  - `FsProjectStore` and `FsBlobStore` wrap the existing disk code and keep the on-disk layout byte-for-byte.
  - `PgProjectStore` (Drizzle, one row per project with the full document in `jsonb`) and `GcsBlobStore` (`@google-cloud/storage`).
- **Service layer:** operations that need both stores (duplicate as option, delete, photos) live in `src/lib/storage/service.ts`.
- **Entry point:** every caller gets its stores from `await getStorage()` in `src/lib/storage/index.ts`, which picks the backends from `DATABASE_URL` and `GCS_BUCKET`.
- **Shared tests:** one contract test suite runs against every implementation.

**Tech Stack:**
- Existing: TypeScript, Next.js 15 route handlers and server components, Vitest, Playwright.
- New runtime: `drizzle-orm`, `postgres` (porsager) and `@google-cloud/storage`.
- New dev: `drizzle-kit`, `@electric-sql/pglite` (in-process Postgres for tests, no Docker needed) and `tsx`.

**Spec:** `docs/superpowers/specs/2026-10-14-mobile-cloud-design.md` (Phase 1 section, plus the Architecture section).

## Global Constraints

**Phase boundary**
- Phase 1 creates no cloud resources. Neon and GCS are used only when `DATABASE_URL` / `GCS_BUCKET` are set. Terraform is Phase 0, auth is Phase 2.

**Backend selection and the disk layout**
- `DATABASE_URL` unset → `FsProjectStore`. `GCS_BUCKET` unset → `FsBlobStore`. Both are rooted at `resolveDataDir()`. The two choices are independent: local Postgres with photos on disk is valid.
- The on-disk layout must not change: `<DATA_DIR>/projects/<id>/project.json` and `<DATA_DIR>/projects/<id>/photos/<photoId>.jpg`.
- Blob keys are `projects/<projectId>/photos/<photoId>.jpg`, built only through `photoKey()` / `projectPrefix()` in `src/lib/storage/ids.ts`. `Photo.path` stays `photos/<photoId>.jpg` for compatibility.

**Callers and validation**
- All storage APIs are async. App code imports from `@/lib/storage` (the index) and calls `await getStorage()` per request. Never cache a `Storage` across requests: tests change `DATA_DIR` per test, and Phase 2 makes it per-user.
- Project ids must match the UUID regex before any storage access, and photo ids must match `PHOTO_ID = /^[A-Za-z0-9_-]+$/`.

**Postgres**
- `owner_id` exists in the schema but is `null` for every row in Phase 1. `PgProjectStore` takes `ownerId: string | null` (default `null`) and filters every query by it.
- The project document in `doc` is validated with `ProjectSchema.parse` on every read and write.
- Migrations are SQL files generated by `drizzle-kit` into `drizzle/` and committed. The app applies them at startup (`src/instrumentation.ts`).
- The `npm run db:migrate` CLI refuses a non-local database unless `MIGRATE_ALLOW_REMOTE=1` is set.

**Versions**
- `drizzle-orm@^0.45.4`, `drizzle-kit@^0.31.11`, `postgres@^3.4.9`, `@google-cloud/storage@^8.4.0`, `@electric-sql/pglite@^0.5.10` (dev), `tsx` (dev, latest 4.x).

**Tests**
- Pg tests use PGlite and GCS tests use an in-memory fake bucket. Neither needs network or Docker.
- Files that use them start with `// @vitest-environment node`.
- No jest-dom: use `toBeTruthy()` / `not.toBeNull()`.

**Must stay green after every task:** `npm test`, `npm run typecheck`, `npm run lint`. After Task 69 and at the end, also `npm run e2e`.

**Deviation from the spec (record it in Task 73):** no `deleted_at` column. Deletes stay permanent, as they are today. Offline sync in Phase 6 refreshes in full, so it needs no tombstones.

## Review Focus

1. **Parallel photo uploads to one project.** Every photo ends up on the project and none is lost. With Postgres, a row lock (`SELECT … FOR UPDATE`) serializes the updates. Tested by the contract's concurrency test (Task 67), which runs against PGlite in Task 70.
2. **Deleting a project whose id is a prefix of another's.** Only that project's photos go: blob prefixes always end in `/`. Tested in the blob contract (Task 67) and in Task 71 for GCS.
3. **Deleting a project removes its photos from the blob store too**, not just the record. This matters most for GCS, where nothing else would clean them up. Tested in the service tests (Task 68).
4. **A database row whose `doc` no longer parses** (a hand edit, or an older schema). The project list skips it instead of failing the home page, matching the disk behaviour. Tested in Task 70.
5. **Running `npm run db:migrate` with a prod `DATABASE_URL` in `.env.local`.** It refuses unless `MIGRATE_ALLOW_REMOTE=1`. This is the garden app's 2-day-outage lesson. Tested in Task 72.

```ts
/**
 * Ids and blob keys. Every storage path or object key is built here, so a
 * request-supplied id is validated before it can name anything.
 */

const UUID_RE = /^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/i;

/** Thrown for any project id that is not a UUID — the path-traversal guard. */
export class InvalidProjectIdError extends Error {
  constructor(id: string) {
    super(`invalid project id: ${JSON.stringify(id)}`);
    this.name = 'InvalidProjectIdError';
  }
}

export function isValidProjectId(id: string): boolean {
  return UUID_RE.test(id);
}

/** Photo ids we generate; anything else in a hand-edited project could name a file elsewhere. */
export const PHOTO_ID = /^[A-Za-z0-9_-]+$/;

/** `projects/<id>/` — every blob of a project lives under this prefix. The trailing slash keeps one id from matching another that starts with it. */
export function projectPrefix(projectId: string): string {
  if (!isValidProjectId(projectId)) throw new InvalidProjectIdError(projectId);
  return `projects/${projectId}/`;
}

/** `projects/<id>/photos/<photoId>.jpg` — built from the ids, never from a stored path. */
export function photoKey(projectId: string, photoId: string): string {
  if (!PHOTO_ID.test(photoId)) throw new Error('invalid photo id');
  return `${projectPrefix(projectId)}photos/${photoId}.jpg`;
}
```

```ts
import { randomUUID } from 'node:crypto';
import { closetFootprint, newCloset } from '../closet/catalog';
import { ProjectSchema, type Project, type ProjectKind } from './schemas';

/** A fresh, unsaved project: a kitchen with the default room, or a closet with the default closet. */
export function newProject(fields: { id?: string; name: string; kind?: ProjectKind }): Project {
  const now = new Date().toISOString();
  const kind = fields.kind ?? 'kitchen';
  const closet = kind === 'closet' ? newCloset() : undefined;
  return ProjectSchema.parse({
    id: fields.id ?? randomUUID(),
    name: fields.name,
    kind,
    units: 'mm',
    createdAt: now,
    updatedAt: now,
    revision: 0,
    photos: [],
    room: {
      // Kitchens start as a 3m × 4m rectangle so the editor has something to
      // draw on; the user replaces it once photos are extracted or the room
      // is sketched. A closet's room is just its footprint.
      polygon: closet
        ? closetFootprint(closet)
        : [
            [0, 0],
            [3000, 0],
            [3000, 4000],
            [0, 4000],
          ],
      walls: Array.from({ length: 4 }, () => ({ id: randomUUID(), thicknessMm: 100 })),
      openings: [],
    },
    items: [],
    ...(closet ? { closet } : {}),
    history: [],
  });
}
```

```ts
import { projectKind, type Project } from '../plan/schemas';

/** What the project list page shows: name, last change, option link, and enough of the plan to draw a thumbnail. */
export type ProjectSummary = Pick<
  Project,
  'id' | 'name' | 'kind' | 'createdAt' | 'updatedAt' | 'revision' | 'room' | 'items' | 'closet' | 'optionOf'
>;

export function toSummary(project: Project): ProjectSummary {
  return {
    id: project.id,
    name: project.name,
    kind: projectKind(project),
    createdAt: project.createdAt,
    updatedAt: project.updatedAt,
    revision: project.revision,
    room: project.room,
    items: project.items,
    ...(project.closet ? { closet: project.closet } : {}),
    ...(project.optionOf ? { optionOf: project.optionOf } : {}),
  };
}

export class ProjectNotFoundError extends Error {
  constructor(id: string) {
    super(`Project not found: ${id}`);
    this.name = 'ProjectNotFoundError';
  }
}

/** Project records. Implementations: FsProjectStore (disk), PgProjectStore (Postgres). */
export interface ProjectStore {
  /** Add a new project. Rejects if the id is not a UUID or is already taken. */
  insert(project: Project): Promise<void>;
  /** The project, or null if there is none with this id (or the id isn't a UUID). */
  load(id: string): Promise<Project | null>;
  /**
   * Load → update → save, atomically per project: concurrent updates run one
   * after another, so none is lost. If `update` throws, nothing is saved.
   * Rejects with ProjectNotFoundError for an unknown project.
   */
  update(id: string, update: (current: Project) => Project | Promise<Project>): Promise<Project>;
  /** Delete the record (not its blobs — see deleteProject in service.ts). False if it didn't exist. */
  remove(id: string): Promise<boolean>;
  /** Every project that parses, newest change first. */
  list(): Promise<ProjectSummary[]>;
  /** Every project whose option group is `groupId` (the original and its options), in any order. */
  group(groupId: string): Promise<Project[]>;
}

/** Bytes by key ("projects/<id>/photos/<photo>.jpg"). Implementations: FsBlobStore (disk), GcsBlobStore. */
export interface BlobStore {
  /** Write (or overwrite) a blob. */
  put(key: string, bytes: Buffer, contentType: string): Promise<void>;
  /** The bytes, or null if there is no such blob. */
  get(key: string): Promise<Buffer | null>;
  /** Delete a blob. Deleting a missing blob is not an error. */
  delete(key: string): Promise<void>;
  /** Delete every blob under `prefix`, which must end in "/". */
  deletePrefix(prefix: string): Promise<void>;
  /** Copy a blob. Resolves false (and copies nothing) if `from` doesn't exist. */
  copy(from: string, to: string): Promise<boolean>;
}

export type Storage = { projects: ProjectStore; blobs: BlobStore };
```

```ts
/**
 * Behaviour every ProjectStore / BlobStore must have. Each implementation's
 * test file calls these with a setup function, so the disk, Postgres and GCS
 * backends are held to exactly the same rules.
 */
import { describe, it, expect, beforeEach, afterEach } from 'vitest';
import { randomUUID } from 'node:crypto';
import { newProject } from '../plan/new-project';
import type { Project } from '../plan/schemas';
import { ProjectNotFoundError, type BlobStore, type ProjectStore } from './store';

export type Setup<T> = () => Promise<{ store: T; teardown?: () => Promise<void> }>;

const at = (p: Project, updatedAt: string): Project => ({ ...p, updatedAt });
const pause = (ms: number) => new Promise((r) => setTimeout(r, ms));

export function describeProjectStore(name: string, setup: Setup<ProjectStore>): void {
  describe(`ProjectStore contract: ${name}`, () => {
    let store: ProjectStore;
    let teardown: (() => Promise<void>) | undefined;
    beforeEach(async () => {
      ({ store, teardown } = await setup());
    });
    afterEach(async () => {
      await teardown?.();
    });

    it('loads what was inserted', async () => {
      const p = newProject({ name: 'Kitchen' });
      await store.insert(p);
      expect(await store.load(p.id)).toEqual(p);
    });

    it('loads null for an unknown id or one that is not a UUID', async () => {
      expect(await store.load(randomUUID())).toBeNull();
      expect(await store.load('../../etc/passwd')).toBeNull();
    });

    it('refuses to insert a taken id or a non-UUID id', async () => {
      const p = newProject({ name: 'A' });
      await store.insert(p);
      await expect(store.insert(p)).rejects.toThrow();
      await expect(store.insert({ ...newProject({ name: 'B' }), id: 'not-a-uuid' })).rejects.toThrow();
    });

    it('updates and returns the saved project', async () => {
      const p = newProject({ name: 'Old' });
      await store.insert(p);
      const next = await store.update(p.id, (cur) => ({ ...cur, name: 'New', revision: cur.revision + 1 }));
      expect(next).toMatchObject({ name: 'New', revision: 1 });
      expect(await store.load(p.id)).toEqual(next);
    });

    it('saves nothing when the update throws', async () => {
      const p = newProject({ name: 'Keep' });
      await store.insert(p);
      await expect(
        store.update(p.id, () => {
          throw new Error('nope');
        })
      ).rejects.toThrow('nope');
      expect(await store.load(p.id)).toEqual(p);
    });

    it('rejects an update of an unknown project with ProjectNotFoundError', async () => {
      await expect(store.update(randomUUID(), (p) => p)).rejects.toBeInstanceOf(ProjectNotFoundError);
      await expect(store.update('not-a-uuid', (p) => p)).rejects.toBeInstanceOf(ProjectNotFoundError);
    });

    it('runs concurrent updates one after another, so none is lost', async () => {
      const p = newProject({ name: 'Photos' });
      await store.insert(p);
      await Promise.all(
        Array.from({ length: 5 }, (_, i) =>
          store.update(p.id, async (cur) => {
            await pause(5);
            return { ...cur, photos: [...cur.photos, { id: `ph${i}`, path: `photos/ph${i}.jpg`, width: 10, height: 10 }] };
          })
        )
      );
      expect((await store.load(p.id))!.photos.map((ph) => ph.id).sort()).toEqual(['ph0', 'ph1', 'ph2', 'ph3', 'ph4']);
    });

    it('removes a project, and reports false for one that is not there', async () => {
      const p = newProject({ name: 'Gone' });
      await store.insert(p);
      expect(await store.remove(p.id)).toBe(true);
      expect(await store.load(p.id)).toBeNull();
      expect(await store.remove(p.id)).toBe(false);
      expect(await store.remove('not-a-uuid')).toBe(false);
    });

    it('lists summaries newest first, without history', async () => {
      await store.insert(at(newProject({ name: 'Older' }), '2026-01-01T00:00:00.000Z'));
      await store.insert(at(newProject({ name: 'Newer', kind: 'closet' }), '2026-02-01T00:00:00.000Z'));
      const list = await store.list();
      expect(list.map((s) => s.name)).toEqual(['Newer', 'Older']);
      expect(list[0]).not.toHaveProperty('history');
      expect(list[0].kind).toBe('closet');
      expect(list[0].closet).toBeTruthy();
    });

    it('finds an option group: the original and its options, nothing else', async () => {
      const original = newProject({ name: 'Kitchen' });
      const option = { ...newProject({ name: 'Kitchen — Option B' }), optionOf: original.id };
      const other = newProject({ name: 'Bathroom' });
      for (const p of [original, option, other]) await store.insert(p);
      const group = await store.group(original.id);
      expect(group.map((p) => p.name).sort()).toEqual(['Kitchen', 'Kitchen — Option B']);
      expect(await store.group(randomUUID())).toEqual([]);
    });
  });
}

export function describeBlobStore(name: string, setup: Setup<BlobStore>): void {
  describe(`BlobStore contract: ${name}`, () => {
    let store: BlobStore;
    let teardown: (() => Promise<void>) | undefined;
    beforeEach(async () => {
      ({ store, teardown } = await setup());
    });
    afterEach(async () => {
      await teardown?.();
    });

    const A = 'projects/p1/photos/a.jpg';

    it('round-trips bytes, and a second put overwrites', async () => {
      await store.put(A, Buffer.from('one'), 'image/jpeg');
      expect((await store.get(A))?.toString()).toBe('one');
      await store.put(A, Buffer.from('two'), 'image/jpeg');
      expect((await store.get(A))?.toString()).toBe('two');
    });

    it('gets null for a missing key', async () => {
      expect(await store.get('projects/p1/photos/missing.jpg')).toBeNull();
    });

    it('deletes a key; deleting a missing key is fine', async () => {
      await store.put(A, Buffer.from('x'), 'image/jpeg');
      await store.delete(A);
      expect(await store.get(A)).toBeNull();
      await expect(store.delete(A)).resolves.toBeUndefined();
    });

    it('deletes everything under a prefix and nothing beside it', async () => {
      await store.put('projects/p1/photos/a.jpg', Buffer.from('a'), 'image/jpeg');
      await store.put('projects/p1/photos/b.jpg', Buffer.from('b'), 'image/jpeg');
      await store.put('projects/p10/photos/c.jpg', Buffer.from('c'), 'image/jpeg');
      await store.deletePrefix('projects/p1/');
      expect(await store.get('projects/p1/photos/a.jpg')).toBeNull();
      expect(await store.get('projects/p1/photos/b.jpg')).toBeNull();
      expect((await store.get('projects/p10/photos/c.jpg'))?.toString()).toBe('c');
      await expect(store.deletePrefix('projects/nothing-here/')).resolves.toBeUndefined();
    });

    it('copies a blob, and reports false when the source is missing', async () => {
      await store.put(A, Buffer.from('copy me'), 'image/jpeg');
      expect(await store.copy(A, 'projects/p2/photos/a.jpg')).toBe(true);
      expect((await store.get('projects/p2/photos/a.jpg'))?.toString()).toBe('copy me');
      expect(await store.copy('projects/p1/photos/none.jpg', 'projects/p2/photos/none.jpg')).toBe(false);
      expect(await store.get('projects/p2/photos/none.jpg')).toBeNull();
    });
  });
}
```

```ts
import { copyFile, mkdir, readFile, rename, rm, writeFile } from 'node:fs/promises';
import { dirname, join } from 'node:path';
import type { BlobStore } from './store';

const SEGMENT = /^[A-Za-z0-9._-]+$/;
const isNotFound = (err: unknown) => (err as NodeJS.ErrnoException)?.code === 'ENOENT';

/**
 * Blobs as files under `root`, at the paths the app has always used
 * (`<DATA_DIR>/projects/<id>/photos/<photo>.jpg`), so existing data needs no move.
 */
export class FsBlobStore implements BlobStore {
  constructor(private readonly root: string) {}

  /** Every key segment must be a plain name: no "..", no empty segment, no backslash. */
  private path(key: string): string {
    const segments = key.split('/');
    if (segments.some((s) => !SEGMENT.test(s) || s === '.' || s === '..')) {
      throw new Error(`invalid blob key: ${JSON.stringify(key)}`);
    }
    return join(this.root, ...segments);
  }

  async put(key: string, bytes: Buffer): Promise<void> {
    const file = this.path(key);
    await mkdir(dirname(file), { recursive: true });
    const tmp = `${file}.tmp`;
    await writeFile(tmp, bytes);
    await rename(tmp, file);
  }

  async get(key: string): Promise<Buffer | null> {
    try {
      return await readFile(this.path(key));
    } catch (err) {
      if (isNotFound(err)) return null;
      throw err;
    }
  }

  async delete(key: string): Promise<void> {
    await rm(this.path(key), { force: true });
  }

  async deletePrefix(prefix: string): Promise<void> {
    if (!prefix.endsWith('/')) throw new Error('prefix must end with "/"');
    await rm(this.path(prefix.slice(0, -1)), { recursive: true, force: true });
  }

  async copy(from: string, to: string): Promise<boolean> {
    const src = this.path(from);
    const dest = this.path(to);
    try {
      await mkdir(dirname(dest), { recursive: true });
      await copyFile(src, dest);
      return true;
    } catch (err) {
      if (isNotFound(err)) return false;
      throw err;
    }
  }
}
```

```ts
import type { Project } from '../plan/schemas';
import { InvalidProjectIdError, isValidProjectId } from './ids';
import { deleteProject, listProjects, loadProject, optionGroup, projectExists, saveProject, updateProject } from './projects';
import { ProjectNotFoundError, type ProjectStore, type ProjectSummary } from './store';

/** Projects as `<dataDir>/projects/<id>/project.json` — the local-dev and test backend. */
export class FsProjectStore implements ProjectStore {
  constructor(private readonly dataDir: string) {}

  async insert(project: Project): Promise<void> {
    if (!isValidProjectId(project.id)) throw new InvalidProjectIdError(project.id);
    if (projectExists(this.dataDir, project.id)) throw new Error(`project already exists: ${project.id}`);
    saveProject(this.dataDir, project);
  }

  async load(id: string): Promise<Project | null> {
    return isValidProjectId(id) && projectExists(this.dataDir, id) ? loadProject(this.dataDir, id) : null;
  }

  async update(id: string, update: (current: Project) => Project | Promise<Project>): Promise<Project> {
    if (!isValidProjectId(id) || !projectExists(this.dataDir, id)) throw new ProjectNotFoundError(id);
    return updateProject(this.dataDir, id, update);
  }

  async remove(id: string): Promise<boolean> {
    return isValidProjectId(id) ? deleteProject(this.dataDir, id) : false;
  }

  async list(): Promise<ProjectSummary[]> {
    return listProjects(this.dataDir);
  }

  async group(groupId: string): Promise<Project[]> {
    return optionGroup(this.dataDir, groupId);
  }
}
```

```ts
/**
 * Storage operations that span project records and blobs. Backend-agnostic:
 * they work on any `Storage`, so the routes behave the same on disk and in
 * the cloud.
 */
import { randomUUID } from 'node:crypto';
import { groupName, nextOptionName, optionGroupId, sortGroup } from '../plan/options';
import { ProjectSchema, type Photo, type Project } from '../plan/schemas';
import { isValidProjectId, PHOTO_ID, photoKey, projectPrefix } from './ids';
import type { Storage } from './store';

/** The projects in option group `groupId`: the original first (if it still exists), then its options oldest first. */
export async function optionGroup(storage: Storage, groupId: string): Promise<Project[]> {
  if (!isValidProjectId(groupId)) return [];
  return sortGroup(await storage.projects.group(groupId), groupId);
}

/**
 * Copy a project as a new design option: a new id and a fresh history,
 * linked to its group's original by `optionOf`, named "<group> — Option <L>",
 * with its photos copied. The source is not changed. Null for an unknown source.
 */
export async function duplicateAsOption(storage: Storage, sourceId: string): Promise<Project | null> {
  const source = await storage.projects.load(sourceId);
  if (!source) return null;
  const groupId = optionGroupId(source);
  const group = await optionGroup(storage, groupId);
  const now = new Date().toISOString();
  const id = randomUUID();
  const { history: _history, ...rest } = source;
  const photos = source.photos.filter((photo) => PHOTO_ID.test(photo.id));
  const copy: Project = ProjectSchema.parse({
    ...rest,
    photos,
    id,
    name: nextOptionName(groupName(group), group.map((p) => p.name)),
    createdAt: now,
    updatedAt: now,
    revision: 0,
    optionOf: groupId,
    history: [],
  });
  // A listed photo whose file is missing is still listed on the copy, as before.
  for (const photo of photos) await storage.blobs.copy(photoKey(source.id, photo.id), photoKey(id, photo.id));
  await storage.projects.insert(copy);
  return copy;
}

/** Delete a project and all its blobs. Permanent: there is no trash. False if it didn't exist. */
export async function deleteProject(storage: Storage, id: string): Promise<boolean> {
  if (!isValidProjectId(id)) return false;
  const removed = await storage.projects.remove(id);
  if (removed) await storage.blobs.deletePrefix(projectPrefix(id));
  return removed;
}

export type PhotoLookup =
  | { ok: true; project: Project; photo: Photo }
  | { ok: false; status: 400 | 404; error: string };

/**
 * Resolve a (projectId, photoId) pair from a request. Only photos listed on
 * the project are found, so a crafted `photoId` can never name another blob.
 */
export async function lookupPhoto(storage: Storage, projectId: string, photoId: string): Promise<PhotoLookup> {
  if (!isValidProjectId(projectId)) return { ok: false, status: 400, error: 'invalid project id' };
  const project = await storage.projects.load(projectId);
  if (!project) return { ok: false, status: 404, error: 'project not found' };
  const photo = project.photos.find((p) => p.id === photoId);
  if (!photo) return { ok: false, status: 404, error: 'photo not found' };
  return { ok: true, project, photo };
}

/** A photo's JPEG bytes, or null if the blob is missing. Throws for a photo id we didn't generate. */
export function readPhoto(storage: Storage, projectId: string, photo: Photo): Promise<Buffer | null> {
  return storage.blobs.get(photoKey(projectId, photo.id));
}

/**
 * Store a (normalized) JPEG and append it to `project.photos`. If the
 * project update fails, the blob is deleted again so no orphan is left.
 */
export async function addPhoto(
  storage: Storage,
  projectId: string,
  jpeg: Buffer,
  dims: { width: number; height: number }
): Promise<Photo> {
  const id = randomUUID();
  const photo: Photo = { id, path: `photos/${id}.jpg`, width: dims.width, height: dims.height };
  const key = photoKey(projectId, id);
  await storage.blobs.put(key, jpeg, 'image/jpeg');
  try {
    await storage.projects.update(projectId, (p) => ({
      ...p,
      photos: [...p.photos, photo],
      updatedAt: new Date().toISOString(),
    }));
  } catch (err) {
    await storage.blobs.delete(key).catch(() => undefined);
    throw err;
  }
  return photo;
}
```

```ts
import { and, desc, eq, isNull, or, sql, type SQL } from 'drizzle-orm';
import { projects } from '../db/schema';
import type { Db } from '../db/types';
import { optionGroupId } from '../plan/options';
import { ProjectSchema, projectKind, type Project } from '../plan/schemas';
import { InvalidProjectIdError, isValidProjectId } from './ids';
import { ProjectNotFoundError, toSummary, type ProjectStore, type ProjectSummary } from './store';

/**
 * Projects in Postgres, one row each, scoped to one owner. `update` locks
 * the row (SELECT … FOR UPDATE) inside a transaction, so concurrent writers
 * — parallel photo uploads, two devices — are applied one after another.
 */
export class PgProjectStore implements ProjectStore {
  constructor(
    private readonly db: Db,
    private readonly ownerId: string | null = null
  ) {}

  private owned(): SQL {
    return this.ownerId === null ? isNull(projects.ownerId) : eq(projects.ownerId, this.ownerId);
  }

  private columns(project: Project) {
    const doc = ProjectSchema.parse(project);
    return {
      name: doc.name,
      kind: projectKind(doc),
      optionOf: doc.optionOf ?? null,
      revision: doc.revision,
      doc,
      createdAt: doc.createdAt,
      updatedAt: doc.updatedAt,
    };
  }

  async insert(project: Project): Promise<void> {
    if (!isValidProjectId(project.id)) throw new InvalidProjectIdError(project.id);
    await this.db.insert(projects).values({ id: project.id, ownerId: this.ownerId, ...this.columns(project) });
  }

  async load(id: string): Promise<Project | null> {
    if (!isValidProjectId(id)) return null;
    const [row] = await this.db
      .select({ doc: projects.doc })
      .from(projects)
      .where(and(eq(projects.id, id), this.owned()))
      .limit(1);
    return row ? ProjectSchema.parse(row.doc) : null;
  }

  async update(id: string, update: (current: Project) => Project | Promise<Project>): Promise<Project> {
    if (!isValidProjectId(id)) throw new ProjectNotFoundError(id);
    return this.db.transaction(async (tx) => {
      const [row] = await tx
        .select({ doc: projects.doc })
        .from(projects)
        .where(and(eq(projects.id, id), this.owned()))
        .for('update');
      if (!row) throw new ProjectNotFoundError(id);
      const next = await update(ProjectSchema.parse(row.doc));
      if (next.id !== id) throw new Error('an update must not change the project id');
      const cols = this.columns(next);
      await tx.update(projects).set(cols).where(eq(projects.id, id));
      return cols.doc;
    });
  }

  async remove(id: string): Promise<boolean> {
    if (!isValidProjectId(id)) return false;
    const gone = await this.db
      .delete(projects)
      .where(and(eq(projects.id, id), this.owned()))
      .returning({ id: projects.id });
    return gone.length > 0;
  }

  async list(): Promise<ProjectSummary[]> {
    // The list never needs history, which is most of a long-lived document.
    const rows = await this.db
      .select({ doc: sql<Project>`${projects.doc} - 'history'` })
      .from(projects)
      .where(this.owned())
      .orderBy(desc(projects.updatedAt));
    return rows.flatMap((row) => {
      const parsed = ProjectSchema.safeParse({ ...row.doc, history: [] });
      return parsed.success ? [toSummary(parsed.data)] : [];
    });
  }

  async group(groupId: string): Promise<Project[]> {
    if (!isValidProjectId(groupId)) return [];
    const rows = await this.db
      .select({ doc: projects.doc })
      .from(projects)
      .where(and(this.owned(), or(eq(projects.id, groupId), eq(projects.optionOf, groupId))));
    return rows
      .flatMap((row) => {
        const parsed = ProjectSchema.safeParse(row.doc);
        return parsed.success ? [parsed.data] : [];
      })
      .filter((p) => optionGroupId(p) === groupId);
  }
}
```

```ts
import type { BlobStore } from './store';

/** The slice of @google-cloud/storage's Bucket that GcsBlobStore uses (so tests can fake it). */
export interface BucketLike {
  file(name: string): {
    save(data: Buffer, options: { contentType: string; resumable: boolean }): Promise<unknown>;
    download(): Promise<[Buffer]>;
    delete(options: { ignoreNotFound: boolean }): Promise<unknown>;
    copy(destination: string): Promise<unknown>;
  };
  deleteFiles(options: { prefix: string; force: boolean }): Promise<unknown>;
}

const isNotFound = (err: unknown) => (err as { code?: unknown })?.code === 404;

/**
 * Blobs as objects in a private GCS bucket, optionally under a key prefix
 * (e.g. "e2e/" so a test run never touches real photos).
 */
export class GcsBlobStore implements BlobStore {
  constructor(
    private readonly bucket: BucketLike,
    private readonly prefix = ''
  ) {}

  private name(key: string): string {
    return `${this.prefix}${key}`;
  }

  async put(key: string, bytes: Buffer, contentType: string): Promise<void> {
    // Photos are a few MB at most: a single-request upload is faster than resumable.
    await this.bucket.file(this.name(key)).save(bytes, { contentType, resumable: false });
  }

  async get(key: string): Promise<Buffer | null> {
    try {
      const [bytes] = await this.bucket.file(this.name(key)).download();
      return bytes;
    } catch (err) {
      if (isNotFound(err)) return null;
      throw err;
    }
  }

  async delete(key: string): Promise<void> {
    await this.bucket.file(this.name(key)).delete({ ignoreNotFound: true });
  }

  async deletePrefix(prefix: string): Promise<void> {
    if (!prefix.endsWith('/')) throw new Error('prefix must end with "/"');
    await this.bucket.deleteFiles({ prefix: this.name(prefix), force: true });
  }

  async copy(from: string, to: string): Promise<boolean> {
    try {
      await this.bucket.file(this.name(from)).copy(this.name(to));
      return true;
    } catch (err) {
      if (isNotFound(err)) return false;
      throw err;
    }
  }
}

/** A store on the real bucket. Credentials come from GOOGLE_APPLICATION_CREDENTIALS (ADC). */
export async function gcsBlobStore(bucketName: string, prefix = ''): Promise<GcsBlobStore> {
  const { Storage } = await import('@google-cloud/storage');
  const bucket = new Storage().bucket(bucketName);
  return new GcsBlobStore(bucket as unknown as BucketLike, prefix);
}
```

The SDK's `Bucket` has overloaded methods, which is why the factory casts with `as unknown as BucketLike`. `copy(string)` on a `File` copies within the same bucket.

```ts
import { drizzle } from 'drizzle-orm/postgres-js';
import postgres from 'postgres';
import * as schema from './schema';
import type { Db } from './types';

// One pool per process, shared by every Next.js route bundle (like the project locks).
const KEY = Symbol.for('kitchen-design.db');
type Holder = { db: Db; client: postgres.Sql };
const holder = () => globalThis as typeof globalThis & { [KEY]?: Holder };

/**
 * The app's database (DATABASE_URL). Small pool, short idle timeout: Neon
 * suspends idle compute and drops connections, and postgres-js reconnects
 * on the next query.
 */
export function getDb(): Db {
  const g = holder();
  if (!g[KEY]) {
    const url = process.env.DATABASE_URL;
    if (!url) throw new Error('DATABASE_URL is not set');
    const client = postgres(url, { max: 5, idle_timeout: 20, connect_timeout: 10 });
    g[KEY] = { client, db: drizzle(client, { schema }) as unknown as Db };
  }
  return g[KEY].db;
}

/** Close the pool (scripts and tests). Safe to call when none is open. */
export async function closeDb(): Promise<void> {
  const g = holder();
  const h = g[KEY];
  delete g[KEY];
  await h?.client.end({ timeout: 5 });
}
```

```ts
import { PHOTO_ID, photoKey } from './ids';
import type { Storage } from './store';

export type ImportReport = { imported: string[]; skipped: string[]; missingPhotos: string[] };

/**
 * Copy every project (and its photos) from `source` to `target`. A project
 * already in the target is skipped, so a failed run can simply be re-run.
 * Photos go first and the record last: a half-imported project is retried
 * on the next run.
 */
export async function importProjects(
  source: Storage,
  target: Storage,
  opts: { dryRun?: boolean } = {}
): Promise<ImportReport> {
  const report: ImportReport = { imported: [], skipped: [], missingPhotos: [] };
  for (const summary of await source.projects.list()) {
    const project = await source.projects.load(summary.id);
    if (!project) continue;
    if (await target.projects.load(project.id)) {
      report.skipped.push(project.id);
      continue;
    }
    for (const photo of project.photos) {
      if (!PHOTO_ID.test(photo.id)) continue;
      const bytes = await source.blobs.get(photoKey(project.id, photo.id));
      if (!bytes) {
        report.missingPhotos.push(`${project.id}/${photo.id}`);
        continue;
      }
      if (!opts.dryRun) await target.blobs.put(photoKey(project.id, photo.id), bytes, 'image/jpeg');
    }
    if (!opts.dryRun) await target.projects.insert(project);
    report.imported.push(project.id);
  }
  return report;
}
```

```ts
/**
 * npm run import:local -- [--data ./data] [--dry-run] [--yes]
 *
 * Copy projects and photos from a local data directory into the configured
 * cloud backends (DATABASE_URL, and GCS_BUCKET for photos). Re-runnable:
 * projects already in the database are skipped. A non-local database needs --yes.
 */
import { resolve } from 'node:path';
import { parseArgs } from 'node:util';
import { closeDb } from '../src/lib/db/client';
import { isLocalDatabase } from '../src/lib/db/remote-guard';
import { importProjects } from '../src/lib/storage/import';
import { fsStorage, getStorage } from '../src/lib/storage';

const { values } = parseArgs({
  options: {
    data: { type: 'string', default: './data' },
    'dry-run': { type: 'boolean', default: false },
    yes: { type: 'boolean', default: false },
  },
});

// The package is CommonJS to tsx (no "type": "module"), so no top-level await.
async function main(): Promise<void> {
  const url = process.env.DATABASE_URL;
  if (!url) {
    console.error('DATABASE_URL is not set — there is nothing to import into.');
    process.exit(1);
  }
  if (!isLocalDatabase(url) && !values.yes && !values['dry-run']) {
    console.error(`Target database is ${new URL(url).hostname}. Re-run with --yes to import into it (or --dry-run to preview).`);
    process.exit(1);
  }
  if (!process.env.GCS_BUCKET) console.warn('GCS_BUCKET is not set: photos will be written to DATA_DIR on this machine.');

  try {
    const report = await importProjects(fsStorage(resolve(values.data!)), await getStorage(), { dryRun: values['dry-run'] });
    console.log(`${values['dry-run'] ? 'Would import' : 'Imported'} ${report.imported.length}, skipped ${report.skipped.length} already present.`);
    if (report.missingPhotos.length > 0) console.warn(`Photos listed but missing on disk: ${report.missingPhotos.join(', ')}`);
  } finally {
    await closeDb();
  }
}

main().catch((err) => {
  console.error(err);
  process.exit(1);
});
```
